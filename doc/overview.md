# Nov

Knowledge visualization — a framework for presenting information so humans can understand it quickly.

## Problem

Most information is delivered sequentially: prose, ordered lists, documents you read top-to-bottom. That works for sequential thinkers. For spatial, associative thinkers it creates friction — forced saccades, lost context, buried salience.

## Goal

Define how to organize and display information as **navigable terrain** rather than readable text:

- Small glanceable units, not paragraphs
- Structure as a graph; layout as a projection
- Zoom into detail without losing place
- Path through exploration informs what matters next
- Stable navigation for muscle memory; adaptive highlighting for relevance

## Scope

Nov is an abstract framework with **profiles** — concrete rule sets for specific contexts (AI responses, PR review, requirements docs, dashboards, etc.).

The framework covers visual components, navigation behavior, and compression — not data schemas or storage.
